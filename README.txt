APÉRO-CONVERSATION — ALLIANCE FRANÇAISE DE LA VALLÉE D’AOSTE

Fichiers prêts à déposer sur GitHub Pages.

1. Créer un NOUVEAU dépôt GitHub (sans toucher au dépôt SAVT) : apero-conversation-alliance.
2. Ajouter à la racine du dépôt : index.html, confidentialite.html, autorisation-image.html, .nojekyll, et le dossier assets/ avec ses images.
3. Dans Settings > Pages > Build and deployment, choisir Deploy from a branch, puis main et /(root), Save.
4. Ouvrir le lien fourni par GitHub Pages et vérifier l'affichage sur ordinateur et smartphone.

ATTENTION : LE FORMULAIRE D'INSCRIPTION EN LIGNE N'EST PAS ACTIF. Il affiche une démonstration seulement. Aucun renseignement n'est transmis ou conservé. Pour le mettre en service, il faut valider l'information RGPD et l'autorisation d'image, choisir un prestataire de collecte sécurisé, configurer la réception réservée au secrétariat et tester le parcours de bout en bout. NE PAS recueillir de données personnelles dans le dépôt GitHub public.

PARCOURS DE PAIEMENT : le participant envoie ses données, l'administration émet et envoie une facture, le participant effectue le virement après réception de la facture, transmet son justificatif à secretariat@alliancefraoste.it, puis reçoit une confirmation après vérification. Les coordonnées bancaires ne sont donc pas affichées sur la page publique.

La page apero-conversation-apercu.html est une version d'aperçu autonome (images intégrées).
